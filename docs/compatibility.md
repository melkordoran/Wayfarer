# Compatibility and release gates

Target: an independently branded AW 5.2/6.2-style replacement. Current status is a development alpha, validated against the pinned Axis servers in the fixture—not a claim of compatibility with the official Active Worlds universe or every historical browser build.

## Evidence-backed coverage

| Area           | Implemented                                                                                                                 | Evidence / remaining limits                                                                                                                                                 |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Authentication | Browser citizen and tourist paths; wrong-password errors                                                                    | Real local Axis sessions, tourist email validation; TLS exercised in separate socket regression                                                                             |
| World entry    | World list, lookup, nonce, attributes, capabilities                                                                         | Real Universe and World; same-world attribute updates preserve the live scene                                                                                               |
| World settings | Caretaker editor for 50 logical fields / 70 attributes, exact baselines, conflict review and observed broadcasts | No server CAS, transaction or durable acknowledgement; ACLs/passwords/admin excluded; uncertain writes require re-entry; see [protocol limits](world-settings-protocol.md) |
| Environment    | Server lighting, six-color sky, fog/visibility, terrain offset, basic water, RWX/X sky/ground and flight rules              | Fresh isolated Axis attributes and Three/UI tests; X bind-pose fixtures are experimental; historical interpolation, clouds, repeating ground and advanced water remain open |
| Property       | Centered sector queries, bounded local cache, unload/revisit, create/change/delete                                          | Two-client mutation checks and deterministic streaming limits/race tests; cache bounds are not a total memory cap                                                           |
| Chat/presence  | Chat, avatars, movement, disconnect; whisper command path                                                                   | Live two-client delivery and coordinate conversion; private-chat/file-transfer families remain open                                                                         |
| Rendering      | RWX and text/binary X, outer ZIP/GZIP, materials, UVs, transforms, RWX protos/masks/PRELIGHT, collision and water           | Original fixtures and shared-path tests; X unit/basis, historical Surface/gamma and full legacy format parity remain open                                                   |
| Avatar assets  | World catalog, rigid RWX joints, experimental weighted X bones, external SEQ/AWSQ/X motions, MSZIP and loaded/fallback diagnostics | Original deformation/reference-pose witnesses and independent instances; CAV, animated scale, splines, unsupported skin transforms and historical parity remain open |
| Gestures       | Searchable explicit motions, one-shot/stop/repeat, hidden first-person lifecycle and scoped submission                      | Fresh isolated two-client positive/neutral observation; immediate replay/coalescing and historical animation fidelity remain open                                           |
| Terrain        | Loaded-cell selection, height/texture previews, canonical row edits, scoped undo/redo and seam-aware terrain geometry       | Fresh isolated two-client edits/denial/restoration; native offline height/material interaction; no atomic compare-and-swap, continuous brush or extended texture appearance |
| Building       | Individual/group transforms, world/primary-local move/rotate handles, grid/relative/angle snapping, canonical undo/redo; signed text and entry-scoped recoverable drafts | Real handle raycasts, two-client canonical group checks, native offline local move/rotate/Undo/Redo and signed group edits; compound edits are not atomic; native drag-cancel and connected-handle QA remain open |
| Model browser  | Loaded-scene catalog, safe name entry, scoped favorites/recent and actual 3D preview                                        | Explicit bounded asset loading; not an object-path directory index or complete historical format support                                                                    |
| Local projects | Autosave, v1/v2 import/export, sparse terrain patches, explicit restore, corrupt/quota safeguards                           | 5 MiB / 5,000-object validation limits; terrain is the original studio page only; undo stays session-scoped                                                                 |
| Contacts/mail  | Contact lists/privacy, explicit consent, manual telegram retrieval and local inbox                                          | One telegram per fetch; submitted is not delivered; no replay/read receipt guarantee                                                                                        |
| Navigation     | First/third person, walking/flying, local and cross-world teleport, bookmarks, effective manual-travel restrictions         | Fresh restricted Axis tourist/caretaker checks; object/server exceptions are separate; full historical physics/vehicle compatibility remains open                           |
| Actions        | Selected create/activate commands, relative teleport and bounded bump portals                                               | Unsupported ownership lock stops subsequent navigation; no full interpreter, smooth warp or automatic media/link execution                                                  |
| Packaging      | macOS Apple Silicon development bundle; isolated-profile native QA launcher; Windows configuration                          | Packaged offline native interaction, exact build/archive matching and scoped cleanup; notarization and native Windows testing pending                                       |

The browser currently advertises build **1682** / version **62**, which the inspected servers accept. It does not impersonate a tested official AW 5.2 or 6.2 executable. The transport supports multiple packet formats, including v4, but version-specific behavior still requires explicit compatibility profiles and real-world fixtures.

## Next release gates

1. Validate and broaden experimental [DirectX geometry](directx-models.md) and [external X animation](directx-animation.md): independently authorized real-world units/basis/reference-space fixtures, CAV, scaled/sheared rigs, animated scale/splines and exact-version playback fidelity. Unsupported geometry uses an original fallback; motion failure retains valid geometry with a warning. Internal MSZIP and separate text/binary X motions now have original numerical coverage; that does not establish historical exporter parity.
2. Expand action handling with deterministic tests; preserve safe behavior for URLs and media.
3. Complete build ergonomics: native drag-cancel and connected handle/terrain interaction QA, surface/object snapping, richer permission feedback, terrain smoothing/continuous brushes and persistent history. World and primary-local axes are implemented; local translation snaps displacement from the drag origin. Dirty drafts retain their originating world entry and canonical baseline through streaming unload/revisit; cross-entry drafts stay copyable but cannot be submitted.
4. Short/immediate gesture retrigger and visual remote-playback compatibility, remaining world-settings controls/environment effects, join invitations, private chat/file transfer and additional server event families.
5. Large-world render/collision/memory profiling beyond the bounded streaming cache, larger terrain operations and extended texture codes.
6. Broader packaged-native connected workflows, native Windows execution and installer QA, reconnect/slow-network tests, code signing/notarization, accessibility review, and licensed-content fixtures. Offline native visits and automated focus tests do not replace a full keyboard/screen-reader audit.

Original fixture assets are deliberately small and cannot establish fidelity for all legacy AW worlds. The offline Commons is clearly labelled; it never pretends to be a connected universe or invents other online users.
