# Wayfarer 0.12.1-alpha.2

The first public alpha release of Wayfarer, an independent desktop client for
Axis virtual worlds inspired by Active Worlds 5.2/6.2.

This release corrects platform-dependent fixture generation found by Linux CI
before alpha.1's binary publication. Original Studio assets and runtime decoder
limits are unchanged; the earlier source tag is preserved.

Explore the original offline Commons, connect to authorized Axis universes,
chat and build with world/local transform tools, canonical Undo/Redo and
signed/fractional inspector editing. Original client code and documentation are
MIT licensed; dependency and asset licenses remain separate.

## Download

`Wayfarer-0.12.1-alpha.2-macos-arm64.zip` is for **macOS Apple Silicon**.
Extract the ZIP to obtain `Wayfarer.app`. The Commons works without an account.
The app is **ad-hoc signed, not Developer ID signed or notarized**. macOS may
block this development build; verify its checksum and source before deciding
whether to trust it. `SHA256SUMS` accompanies the download.

From a directory containing both downloaded files:

```sh
shasum -a 256 -c SHA256SUMS
```

No Windows or Linux binaries are supplied: native testing for those platforms
is incomplete. Source build instructions are in the
[README](https://github.com/melkordoran/Wayfarer/blob/v0.12.1-alpha.2/README.md).

## Verification

- 2,503 tests in 103 files passed with official Node 22.22.2 and its bundled zlib,
  including an independently refreshed clean source checkout.
- TypeScript, production build/runtime guard and public-source audit passed;
  production dependency audit reported zero vulnerabilities.
- The macOS package passed strict/deep ad-hoc signature and build-byte checks,
  with ten verified notice files.
- A fresh offline native check covered The Commons, mouse capture/release,
  building, signed fractional input, Apply/Undo/Redo and Local-axis controls.
  The owned app quit normally with an empty log. No live world was contacted.

## Scope and limits

This is not an official Active Worlds browser, a complete AW replacement or a
security-certified client. Historical content compatibility, CAV, full
actions/physics, large-world performance, accessibility, connected-native
workflow coverage and release signing remain unfinished.

Server software, proprietary AW content, credentials, private QA profiles and
cached world assets are not distributed. Use authorized worlds, validated TLS
for remote deployments and backups of important projects/worlds.
